# v0.0.4「安心可用版」

## 版本目标

让用户可以放心长期记账：升级、恢复和双机同步不丢数据，同时把重复账单压缩为一次点击。

## 必须交付

- 数据库 v6：账单与分类增加逻辑修订号，冲突判断优先使用修订号，再使用时间和确定性规则。
- 完整备份 3.0：包含账单、分类、预算、偏好和快捷学习规则，带 SHA-256 完整性校验；兼容 1.0/2.0。
- 恢复预检：展示备份版本和内容数量，校验失败不写入，恢复前先创建当前数据库快照。
- 公共 Documents 备份改为显式授权，默认关闭。
- 更新包限制为受信任 HTTPS 域名，并验证包名、签名和可选 SHA-256。
- 首页常用账单：自动聚合、手动固定、隐藏、一键复记、防连点重复。
- CI 自动执行单元测试、Lint、Android 测试编译和 Debug 构建。

## 暂不纳入

云端账号、银行卡自动导入、周期提醒、更多主题和图表、依赖大版本升级。

## 发布指标

- 单元测试、Lint、Debug 构建、Android 测试 APK 构建全部通过。
- v5→v6 迁移测试通过；v1～v5 的真实升级包按发布清单人工覆盖安装。
- 损坏或篡改备份无法进入恢复写入阶段。
- 同一同步包重复发送不产生重复记录；更高修订号不受设备时钟偏差影响。
- 同一常用账单 1.2 秒内重复点击只入账一次。
