# 沅满记账 v0.0.4

账户 Tab 重构与资产全景，交互体验全面优化与官方标准图标库升级。

## 新增

- 账户重构：账户详情页、对账流程、储蓄计划与计划详情、发薪自动分账
- 资产全景页：总资产与构成一览，重构净值走势图原点与月份轴布局
- 账户图标库升级：接入 Simple Icons、Tabler Icons、Font Awesome 官方正版矢量库，扩充至 33 种细分资产图标，彻底移除手绘 XML
- 暗色主题色彩自适应：暗色模式下 Apple Pay 自动转为银白高亮，全局低明度颜色平滑提亮确保高对比度
- 应用内更新：设置页可检查新版本，安装前校验包名、签名与 SHA-256
- 首次启动历史账本自检：应用冷启动时自动探测本地公共备份，弹窗指引一键无缝还原所有流水、账户、计划与个性化设置
- 快捷记账设置页

## 改进

- 备份与卸载恢复加固：彻底修复冷启动自动备份覆盖历史公共快照与 DataStore 内存缓存反冲的问题，全量数据纳入最高安全级别卸载保护
- 二级页面返回交互：接入退出动画过渡管道，彻底消除返回上一级时的卡片闪屏与黑底
- 月度预算设置：滑块第 0 档设为未设置停靠最左侧，向右拖动 500 起步平滑递增
- 账单明细：右上角月份禁止切换至未来月份，滚轮选择器动态过滤未来年月
- 弹窗体验：ModalBottomSheet 遮罩平铺覆盖状态栏弱化，Toast 升级为顶层 Popup 并增加环境发光光晕
- 数据管理：修复“清空全部数据”未清空资金账户与攒钱计划的问题，现已支持全量一键彻底清空
- 备份/恢复：JSON 备份格式完善，CSV 导入导出修正
- 首页、明细、统计、设置页多处交互与性能优化

## 安装

- 数据库版本保持 v5，可直接覆盖安装 v0.0.3 升级，无需卸载
- 发布包与校验文件：`app-release.apk`、`app-release.apk.sha256`
