# 沅满记账 v0.0.5

一致性收尾版：修复桌面组件入口失效，补齐更新包与备份校验，把已完成但未接线的功能接到界面上，统一隐私与删除体验，并重做发薪分配与全部底部弹层的排版配色。

## 修复

- 桌面组件快捷入口：点「记一笔 / 支出 / 收入 / 看统计」不再崩溃并直达对应页面。此前这些入口会导航到未注册的路由（二级页由悬浮栈渲染，NavHost 只注册了 4 个一级页），点击即抛异常；现在统一由二级页栈接收外部路由。
- 更新包校验补全：下载完成后与打开安装器前各校验一次，覆盖包名、签名与 SHA-256 摘要（发布方提供 `app-release.apk.sha256` 时）。此前仅比对文件大小，缓存的安装包也可能被替换。
- 备份完整性清单：手动备份到文档时同时发布 `yuanman_backup_manifest.json`，记录数据库、偏好与账户快照的 SHA-256；恢复前逐项校验，摘要不符即停止恢复且不改动现有数据。未带清单的老备份仍按原有 SQLite 校验恢复。
- 同步会话密钥改为临时 ECDH 协商：不再用握手报文里明文交换的随机数与固定口令派生密钥，被动监听局域网无法复算会话密钥。
- 同步握手双方显示 6 位核对码：同意同步前核对两端数字一致即可排除中间人，握手失败提示也改为按本机版本提示升级。
- 发薪试算不再误报：试算用的入账账户默认避开规则目标账户。此前固定取「第一个有余额的账户」，若它恰好是某条转账户规则的目标，页面会同时显示「0 条规则生效」和下方「1 步 · 100%」，自相矛盾。
- 发薪分配页薪资档位被裁切：「¥25,000」曾显示成「¥2!」，且「假设薪资:」标签会随横向滚动一起划出屏幕只留残缺笔画。
- 首页收支看板：「¥」被挤到金额数字下方。金额沿用了 displayMedium 的 52sp 行高，行盒下半截是空白，与金额共用底对齐的小号「¥」因此被推到很远。
- 圆角与图标细节：修复分类网格残留滚动偏移裁切首行图标、账户核对卡片在浅色下的背景错乱。

## 新增

- 攒钱计划自适应展示：账户页计划卡按数量切换形态——只有 1 个计划时是独占整行的宽卡（显示专款账户与「还差多少」），2~4 个排成两列网格全部可见（不再需要横滑找），5 个及以上折叠为前 4 个并在下方给出「还有 N 个计划」入口，点击进入新的「全部攒钱计划」页浏览。区块头同时显示计划总数。
- 计划置顶：长按计划卡（或「全部攒钱计划」页里长按）可「置顶计划 / 取消置顶」，置顶的计划不受创建顺序限制、排在最前，卡片上有图钉标识。
- 同步核对码：设备同步弹层与对方请求弹窗同时显示同一个 6 位数字，核对一致再继续。
- JSON 备份导入导出：数据管理新增「导出 JSON 备份」与「导入 JSON 备份」，导出文件含分类、全部账单与账户/计划数据，可分享到聊天工具或网盘长期保存。
- 统计页可直接跳周期：周、月、年三种周期点标题即可打开对应的周/年选择器（此前只能一期期翻）。
- 闪电记账支持日期时间：`3/5 电影 40`、`2026-03-05 14:30`、`3月5日`、`下午3点`、`昨天` 等写法均可识别，年月日时分秒都可只写一部分，缺的按「今年 / 本月 / 今日 / 00:00」补全；解析出的时间显示在输入行胶囊上，点按即用滚轮改，改完随账单一起保存。
- 预算金额可直接输入：首页与设置页的月度预算弹窗，点大金额即可手打任意数额（支持到分位），拖滑杆与手输双向同步；滑杆档位仍覆盖 100~100,000 元的常见目标。
- 发薪试算可自定义条件：「薪资」点开可直接输入真实到手金额（支持到分），「入账账户」可选任意资金账户，试算结果实时跟随，不再受预设档位限制。

## 改进

- 发薪分配方案页重做：配色统一走主题语义色（分流取 secondary 蓝、清欠取 tertiary 靛），深浅色模式下不再失配；文案去营销腔——「薪资智能分流引擎」改为「自动分账」、「执行规则链路」改为「分配规则」、「分账执行履历」改为「执行记录」、「兜底守护 · 智能清欠」改为「结余清欠」，顶栏「薪资到账智能分流与自动储蓄」副标题直接去掉。
- 发薪分配可读性：分流占比条改为划转段（主色）与留存段（中性灰）双色常驻并配同色图例，此前 0% 与 100% 划转都是同一条满格绿条；总开关关闭时动线看板整体降透明度并把「N步执行/结余清零」改为「已暂停」，规则链路与清欠卡片同步显示暂停态；未生效的规则会逐条列出原因（如「自转跳过」「来源资金不足」），而不是只显示「0 条规则生效」。
- 账户核对页对账周期改为右上角下拉：不再占一整行，点右上角胶囊直选每周 / 每 2 周 / 每月 / 每季度 / 每半年 / 每年，需要精细步进时选「自定义…」进入原弹层。
- 底部弹层排版统一：新增共享标题组件，标题统一为 16sp 粗体 + 11.5sp 副标题，此前 15/16/20sp 三档标题与 18/20dp 两种内边距并存；主按钮统一 48dp 高、12dp 圆角。覆盖周期选择、资金对账、方案编辑、计划表单、账户表单、转账、手动补分、账单详情、选择分类、闪电记账选账户、日期 / 周 / 年 / 月选择、主题外观、数据管理、设备同步等全部弹层。
- 弹层配色修正：账户卡「默认收入」徽章不再写死浅色模式的绿（深色下与旁边「默认支出」不一致）、对账差额提示改用主题错误色（此前写死浅色红，深色下不切换）、新建计划默认色与账户默认色统一取同一常量。
- 首页隐私模式生效：顶部收支看板、预算进度、账单列表与快捷记账账户金额与账户页共用同一偏好。金额后的隐私小眼睛已移除（隐私开关仍可在账户页顶部切换），避免误触金额末几位即可切走金额显示。
- 首页翻月不再空白：翻到历史月份后列表展示该月全部账单（按时间倒序），标题与空态文案随之切换为「N月账单」。
- 统计页收入维度：走势图跟随「支出结构 / 收入结构」切换为收入走势，关键结论卡新增收入环比。
- 明细页删除可撤销：与首页口径一致，删除后可通过 Toast 上的「撤销」立即恢复。
- 明细页筛选由「全部方式」改为「全部账户」：筛选行直接列出你的资金账户，点账户即筛出该账户的账单，可多选叠加；历史账单里的旧写法（如「微信支付」「微信零钱」）按账户页同一套匹配归类，未归属任何账户的方式收进「其它方式」。
- 关于页接线：「关于沅满」底部入口可打开关于弹层（应用图标、版本与检查更新）。
- 设置页头部改为与首页顶部同款底纹卡（素面底 + 低对比斜向细纹理 + 主色柔光晕 + 细描边），纹理连续铺到状态栏，与明细、统计、账户页头部保持同一视觉语言。
- 代码清理：删除未使用的账户 Room 层与旧版明文同步实现、无引用组件与死参数，减少后续误改。

## 安装

- 数据库版本仍为 6，可直接覆盖安装 v0.0.4 及更早版本，无需卸载。
- 发布包与校验文件：`app-release.apk`、`app-release.apk.sha256`，两者需同时上传。

## 兼容性提示

- 设备同步协议升级到 v4：两端都升级到 v0.0.5 后才能同步，旧版本会提示协议不匹配。
