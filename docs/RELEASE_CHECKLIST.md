# 发布检查表

## 自动门槛

- [ ] `testDebugUnitTest` 通过。
- [ ] `lintDebug` 通过既有 baseline，且没有新增未评估警告。
- [ ] `assembleDebugAndroidTest` 与 `assembleDebug` 通过。
- [ ] Room schema 已提交，数据库版本和迁移链连续。

## 数据安全

- [ ] 使用带账单、分类、预算和快捷学习规则的数据分别从 v0.0.1、v0.0.2、v0.0.3 覆盖安装。
- [ ] 完整备份导出后可预览并恢复；篡改一个金额后恢复被拒绝。
- [ ] 旧版 1.0/2.0 JSON 备份仍可导入。
- [ ] 恢复失败时现有数据库保持可用。
- [ ] 开启与关闭“卸载后自动恢复”时，公共 Documents 副本行为符合提示。

## 同步与更新

- [ ] 两台设备验证新增、编辑、删除、断网重试和重复同步。
- [ ] 两台设备时间不一致时，更高 revision 的修改获胜。
- [ ] 正式 APK 可覆盖安装上一正式版本，且签名验证通过。
- [ ] Release 同时上传 `app-release.apk` 与自动生成的 `app-release.apk.sha256`。
- [ ] 错误包名、错误签名、错误 SHA-256 的安装包均被拒绝。

## 核心体验

- [ ] 首页快捷记账、常用账单、编辑、删除和撤销可用。
- [ ] 常用账单支持固定、取消固定和隐藏；快速连点不会重复入账。
- [ ] API 24、29、34 至少各完成一轮首页、明细、统计、设置烟测。
- [ ] 内部试用 72 小时无 P0/P1 问题后创建标签与 Release。
