# 沅满记账

沅满记账是一款 Android 本地优先账本，提供快捷记账、账单明细、预算复盘、统计图表、CSV 导入导出、完整备份、局域网设备同步和桌面组件。

## 数据与网络说明

- 账单默认保存在本机 Room 数据库中。
- 如果设备开启 Android 系统备份，系统可能按其账号与设备策略备份应用私有数据；这由 Android 设置控制。
- 配置了 `android:hasFragileUserData="true"`：在 Android 10 (API 29) 及以上设备上，用户卸载应用时系统会弹窗提示是否保留应用数据，防止卸载丢失历史账本。
- 检查更新时会访问 GitHub Releases；安装包在下载完成与打开安装器前各校验一次，包括包名、签名，以及发布提供 `app-release.apk.sha256` 时的 SHA-256 摘要，任一项不通过都会阻止安装。
- 设备同步仅在用户授权后通过同一局域网传输，双向合并分类与账单（按修订号/时间取新，删除以墓碑传播）。会话密钥由两端临时 ECDH 协商，报文使用 AES-GCM 加密；握手时双方屏幕显示同一个 6 位核对码，核对一致再确认同步即可排除中间人。账户、攒钱计划与偏好不参与同步。
- “卸载后自动恢复”默认关闭。开启后数据库副本会写入公共 Documents/Yuanman；关闭时会移除该公共副本。
- 手动完整备份包含账单、分类、账户、攒钱计划、对账周期、预算、偏好和快捷记账学习规则，并附带记录各快照 SHA-256 的完整性清单；恢复前逐项校验，摘要不符即拒绝写入（未带清单的老备份仍按原有 SQLite 校验恢复）。
- 数据管理还提供 JSON 备份的导入导出：导出文件含分类、全部账单与账户/计划数据，可自行保存到网盘或聊天工具；导入按同一套合并规则写回。
- 编辑账户余额会生成带说明、可删除/恢复的“账户余额调整”流水，方便对账并保留可追溯记录。
- 版本升级只允许执行经过验证的 Room 迁移；升级前会保留安全快照，禁止用空库或旧快照覆盖已有历史数据。恢复判断不会把系统默认分类误认为用户历史数据。发布前必须用带历史账单的旧版数据库做覆盖安装验证。

## 本地构建

需要 JDK 17 和 Android SDK 34。

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

Release 构建要求 `app/keystore/yuanman-release.jks` 及 `local.properties` 中的签名配置，缺失时构建会主动失败，避免生成无法覆盖安装的升级包。
`assembleRelease` 完成后会在 APK 旁生成 `app-release.apk.sha256`，发布时应与 APK 一起上传。

版本发布说明按版本记录在 [docs/release-notes](docs/release-notes)，当前版本见 [docs/release-notes/v0.0.5.md](docs/release-notes/v0.0.5.md)。
